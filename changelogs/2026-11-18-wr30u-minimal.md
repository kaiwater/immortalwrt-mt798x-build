# 2026-11-18 WR30U 单路基础镜像修正

## 问题

`wr30u-minimal-20261118` 第一版误用了 MTK 的 `mt7981-ax3000.config` 作为基线，
导致 `coreutils` 等基础包和自定义软件缺失，镜像内容与 rax3000m 基线不一致。

正确基线是 `defconfig/rax3000m-openclash.config`：WR30U 已经包含在里面，
软件集合也已经处理好（代理等为 `=m`，不会进镜像）。

## 修正

从 `rax3000m-openclash.config` 生成 `defconfig/wr30u-minimal.config`：

- 只保留 `xiaomi_mi-router-wr30u-stock` / `xiaomi_mi-router-wr30u-ubootmod`
- 彻底去掉：
  - `luci-app-openclash` / `luci-app-passwall` / `sing-box`
  - `ksmbd` / `luci-app-samba4` / `samba4`
  - `luci-app-diskman` / `geoview`
  - USB / exfat / vfat / ntfs3 / automount / ruby
- 保留：
  - `coreutils`、`coreutils-nohup` 等基础包
  - 配置里原有的自定义软件
  - `dnsmasq-full`（旧 25.4MB 基线同样包含）

## 结果

- kernel：6.12.116（chasey-dev 25.12）
- rootfs：20,466,672 B（19.5 MiB）
- stock sysupgrade：25,098,540 B（23.9 MiB）
- ubootmod sysupgrade：26,784,050 B（25.5 MiB）
- release：`wr30u-minimal-20261118`（替换第一版）

## 布局与刷机（不可交叉）

| 变体 | 镜像 | 说明 |
| --- | --- | --- |
| stock | `*-stock-squashfs-sysupgrade.bin` + `*-stock-initramfs-factory.ubi` | 原厂 U-Boot / 原厂分区 |
| ubootmod | `*-ubootmod-squashfs-sysupgrade.itb` + `*-ubootmod-initramfs-recovery.itb` + `preloader.bin` + `bl31-uboot.fip` | OpenWrt U-Boot 布局 |

**stock 和 ubootmod 的镜像不能互刷**，否则会变砖。
